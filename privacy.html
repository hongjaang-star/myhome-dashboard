MyHome 대시보드 개인정보처리방침

시행일: 2026년 10월 18일 · 서비스 주소: https://hongjaang-star.github.io/myhome-dashboard/
요약 — MyHome 은 운영 서버가 없는 개인용 대시보드입니다. 여러분의 데이터는 여러분 자신의 브라우저와 여러분 자신의 Google Drive 에만 저장되며, 개발자를 포함한 누구에게도 전송·수집·공유되지 않습니다.

1. 처리하는 정보

  • 대시보드 데이터: 위젯 배치, 테마, 즐겨찾기, 메모, 달력 일정, 날씨 도시 이름
  • Google 계정 이메일 주소: 로그인한 계정을 화면에 표시하고 다음 로그인 시 계정을 미리 선택하기 위해 사용
  • Google 액세스 토큰: Google Drive 에 데이터를 저장·불러오기 위한 임시 인증값 (약 1시간 유효)

2. 저장 위치

  • 브라우저 저장소(localStorage): 위 정보는 사용 중인 기기의 브라우저에 저장됩니다.
  • 본인의 Google Drive: Google 로그인 시 대시보드 데이터가 내 드라이브 › MyHome Dashboard › dashboard_data.json 파일로 저장됩니다.
  • MyHome 은 별도의 서버나 데이터베이스를 운영하지 않으며, 개발자는 위 정보에 접근할 수 없습니다.

3. Google 사용자 데이터의 사용 범위

  • 요청하는 권한은 https://www.googleapis.com/auth/drive.file 하나입니다. 이 권한으로는 MyHome 이 직접 만든 파일만 읽고 쓸 수 있으며, Drive 의 다른 파일은 볼 수 없습니다.
  • Google 사용자 데이터는 대시보드 데이터의 저장·불러오기 기능에만 사용하며, 광고·분석·판매·제3자 제공에 사용하지 않습니다.
  • MyHome 의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

4. 외부 서비스

  • Google 로그인·Google Drive API (Google LLC): 인증과 데이터 저장. Google 개인정보처리방침
  • wttr.in: 날씨 위젯이 설정한 도시 이름으로 날씨를 조회합니다. 도시 이름 외 개인정보는 전송하지 않습니다.
  • GitHub Pages (GitHub, Inc.): 웹페이지 파일을 제공하며, 일반적인 웹 접속 기록이 GitHub 에 남을 수 있습니다.
  • 즐겨찾기 아이콘 표시를 위해 등록한 사이트의 아이콘(favicon) 이미지를 해당 사이트에서 불러옵니다.

5. 보관 기간과 삭제

  • 브라우저 데이터: 대시보드 설정 › 로그아웃 시 "이 기기 데이터도 삭제"를 선택하거나 브라우저의 사이트 데이터를 지우면 삭제됩니다.
  • Drive 데이터: Google Drive 에서 MyHome Dashboard 폴더를 삭제하면 됩니다.
  • 권한 철회: 설정 › 로그아웃 시 토큰이 폐기되며, Google 계정 › 서드파티 앱 액세스에서도 언제든 철회할 수 있습니다.

6. 쿠키와 추적

MyHome 은 광고·분석용 쿠키나 추적 도구를 사용하지 않습니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지에 게시합니다. 문의는 GitHub 저장소의 Issues 로 남겨 주세요.

Privacy Policy (English summary)

MyHome is a personal dashboard with no backend server. Your dashboard data (layout, theme, bookmarks, memos, calendar events, weather city) is stored only in your browser's localStorage and, when you sign in with Google, in a single file in your own Google Drive (MyHome Dashboard/dashboard_data.json). The only Google scope requested is drive.file, which allows access solely to files created by this app. Google user data is used only to save and load your dashboard, is never sent to the developer or any third party, and is not used for advertising or analytics. MyHome's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can delete your data by removing the Drive folder and signing out (with the "delete local data" option), and revoke access at myaccount.google.com/permissions. Contact: GitHub Issues.
